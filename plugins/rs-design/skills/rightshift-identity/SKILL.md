# RightShift Identity (Startup Brand Kit Guide)

A step-by-step how-to guide, built for the Accelerator, with ready-to-fill Claude prompts: Step 1 gather reference designs, Step 2 palette and Google Font variations (as a preview image and HTML), Step 3 SVG logo, Step 4 user flow (Mermaid), Step 5 lo-fi HTML wireframe, plus links for stock images and AI image tools.

## When to use

Use when a founder or early-stage client needs a lightweight brand identity and early design assets rather than an agency engagement. Inputs: startup or product name, vision, target audience, and optionally mood or style preferences and competitor visual references. Despite the name this is a guide for a startup's own brand, not RightShift's brand rules. The prompt is a Notion how-to with a header, tables of contents, example screenshots and external tool links; follow the steps and prompt templates in it. The templated prompts contain italic placeholders (product type, industry, brand personality and so on) that must be replaced with the user's values; the QuickFit examples are illustrations only.

## Not for

Not for designing product screens in Figma (use `saas-uiux-designer-figma`) or evaluating an existing page (use the evaluation skills here). Not for building the site or product in code (`rs-prototype`, `rs-delivery`).

## How to run

Read `resources/prompt.md` and follow it exactly — it is the canonical prompt (source:
`src/plugins/rs-design/prompts/rightshift-identity/current/rightshift-identity-v1.md`). Ask the user for any required inputs it lists
before starting.
